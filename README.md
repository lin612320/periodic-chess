# 元素周期表飞行棋

> 高三的傍晚，五点四十。窗外是橙色的，广播里放着谁都会哼的那首歌。
> 你提着煎饼果子走进教室，把《化学反应原理》翻到最后一页，摸出那台按键已经松了的科学计算器。
> 六面骰子是一个 `6×RAN+0.5`，棋盘是 118 个元素。

一个纯 HTML / CSS / JavaScript 的网页小游戏，没有任何构建步骤、没有 npm 依赖、没有前端框架。

---

## 直接开玩

**双击 `index.html`** 就能玩。单机、人机对战、断网都行。

> 之所以能双击就跑：全站用经典 `<script>` 顺序加载，不用 ES module（`file://` 下 module 会被 CORS 拦死）。

## 局域网联机

浏览器不能自己开监听端口，所以联机需要一个本地中转。**你的电脑已经装了 Node.js**，一条命令就好：

```bash
node server.js
```

或者直接双击 **`启动联机.bat`**。

终端会打印出内网地址，形如：

```
  本机：    http://127.0.0.1:18080
  局域网：  http://192.168.1.7:18080   (WLAN)
```

同一 WiFi 下的手机 / 平板 / 另一台电脑，浏览器输入那个 `192.168.x.x` 地址即可。

进游戏点「**局域网联机**」→ 填**同一个房间码**和各自的昵称 → 第一个进房的人是房主 → 房主点「开局」。

> 端口被占用就换一个：`node server.js 19000`

### 联机是怎么保证不出错的

**主机权威（host-authoritative）**：

- 所有骰子、方向位移、决斗的随机数**只在房主机器上生成**
- 房主把一次回合产生的「事件流」广播出去，客机按同一份事件流回放动画
- 客机只发「意图」（我要掷骰 / 我选他决斗），永远不改状态

所以改不了随机数，也不会出现两台机器各算各的、越走越偏。

再加三道保险：

| 保险 | 解决什么 |
|---|---|
| **grant 出手授权**：房主轮到谁，才单独给那个座位发一条授权；客机只有收到授权才点亮骰子按钮，点下去立刻锁住 | 按钮亮着却点不动、连点重复掷骰 |
| **回合结束发快照**：每批事件播完，房主补一条权威快照（位置 / 回合 / 阶段），客机在动画间隙对齐 | 漏包、动画卡住导致的两端位置不一致 |
| **45 秒看门狗 + 异常回收**：客机某批事件播太久就强制收尾；房主回合里任何异常都会把「计算中」解锁并提示 | 「点了没反应」「永远卡在计算中」 |

## 玩法

从 **1 号氢**出发，沿元素序号走到 **118 号鿫**。

| 规则 | 说明 |
|---|---|
| 骰子 | 科学计算器 `6×RAN+0.5`，四舍五入 → 1~6（严格均匀） |
| 胜负 | 必须**恰好停在 118** 才算赢 |
| 溢流 | 步子越过 118，就从第 7 周期第 1 格 **Fr(87)** 接着走剩余步数 |
| 镧系/锕系 | 第 6、7 周期那块**入口格**是暗门：**恰好停在这一格**才拐进下面两行，系里走完剩余步数，最后一个元素自动回主表（Lu→Hf，Lr→Rf）；从旁边路过不算 |
| 人数 | 2~4 人，任意座位可设「真人」或「人机」 |

### 特殊格

棋盘上共 35 个特殊格（约 30%），用中文单字标记：

| 标记 | 名称 | 效果 |
|:---:|---|---|
| **斗** | 决斗 | 选一名对手，轮流按 `RAN`，先出 **≥0.9** 者胜；败者停一回合。踩中格子的人先按。 |
| **眠** | 睡觉 | 停一回合。 |
| **再** | 多摇一次 | 本回合再掷一次，可连锁。 |
| **风** | 龙卷风 | `118×RAN+0.5`，直接传送到随机元素格。 |
| **↑ ↓ ← →** | 方向格 | 按周期表方向位移：上下走 1 个周期，左右走 3~5 个族。前方没路就原地不动。 |

> 方向格和龙卷风位移之后**不再二次触发**特殊格，避免连锁爆炸。
> 位移后恰好落在 118 也算赢。

### 两个公式为什么是对的

```
RAN ∈ [0, 1)
6·RAN ∈ [0, 6)  →  +0.5  →  [0.5, 6.5)  →  四舍五入 → 1~6，每段宽度 1，严格均匀
```
`+0.5` 正好抵消掉 `[0, 0.5)` 会被舍成 0 的那一段，所以 0 永远不出现。

`118×RAN+0.5` → `[0.5, 118.5)` → 1~118，同样均匀。

决斗 `RAN ≥ 0.9` 命中率 10%，双方轮流按，先手胜率约 52%。

## 界面上有什么

### 序章：六幕，每一幕都要你动一下手

不是看字幕，是六件事：

| 幕 | 你要做的 | 会发生什么 |
|:--:|---|---|
| 1 | **把人群拨开** | 鼠标靠近，校门口的小人影往两边散开 |
| 2 | **左右移动——你在控制太阳** | 太阳跟着鼠标横移，梧桐树影实时拉长/缩短、角度翻转。太阳低时影子最长（实测 64px → 27px） |
| 3 | **翻一翻，今天吃哪个** | 三只纸袋（煎饼果子 / 稻稻香饭团 / 实惠快餐），悬停翻面，**点一个才放你走** |
| 4 | **划过去，把灯一盏盏点起来** | 教室座位网格（带 3D 透视），鼠标划过的座位依次亮起 |
| 5 | **把门推开** | 按住鼠标往两边拖，两扇门板分开，门缝里漏出暖光，开到 62% 才解锁 |
| 6 | **按一下 RAN** | 真的按下去。LCD 当场算：`0.824` → `4.944 + 0.5` → `Rnd = 5`，然后才进游戏 |

第 3、5、6 幕是**有门槛的**：按钮会变成「翻一翻，今天吃哪个」「把门推开」「按一下 RAN」并锁住，动作没做完就点不过去。

最后一下按 RAN，其实就是进游戏后每一回合都要做的那个动作 —— 序章在教你按哪个键。

- 文字逐行浮现（错开 620ms），每幕暖光会挪到画面另一个位置
- 点 / 空格 / 滚轮 / 「轻触继续」推进，随时可「跳过序章」
- 鼠标移动会把夕阳、云霞、窗帘按不同深度推开

#### 序章的声音：跟着光走

序章底部有个「♪ 声音」开关（默认关）。打开后，**第 2 幕不是放音乐，是把这一天的空气吹给你听**：

| 你把太阳…… | 你听到的 |
|---|---|
| 推到**左边**（位置低、影子最长） | 风压得低而闷（截止 **305 Hz**、音量 **0.17**），远处城市的低频更厚 |
| 推到**右边**（位置升高、影子变短） | 风变细变通透（**1460 Hz**、音量 **0.10**），低频退下去 |

一整层全是**噪声塑形**，没有一个音调性的 drone——所以不会有“电子嗡嗡”。太阳位置只驱动亮暗和风大风小，不改音高。

其余几幕各配一点具体的声音：拨人群的沙沙、翻纸袋的纸声、座位点亮的一声轻响、推门的低频风声、计算器按键的咔哒。

### 元素知识卡

鼠标悬停在任何一个元素格上，弹出该元素的卡片：

| 内容 | 例 |
|---|---|
| 序号 / 符号 / 中文名 | 26 · Fe · 铁 |
| 周期族 | 第 4 周期 · 第 8 族 |
| 相对原子质量 | 55.85 |
| 电子层排布 | 2, 8, 14, 2 |
| 最外层电子数 | 2 |
| 能级排布式 | `1s² 2s² 2p⁶ 3s² 3p⁶ 3d⁶ 4s²` |
| 高中常考考点 | Fe³⁺ 遇 KSCN 变血红色；Fe(OH)₂ 白色→灰绿→红褐… |

- 118 个元素全都有卡片，高频考点元素写了专门的知识点
- 能级排布是程序按 Aufbau 顺序算出来的，Cr / Cu / Nb / Mo / Ru / Rh / Pd / Ag / Pt / Au 的反常排布单独写死
- 卡片颜色跟着元素类别走（过渡金属金、卤素紫、碱金属橙红…）
- 触屏设备上点一下格子也能弹

### 鼠标交互

- **元素格磁吸**：格子会朝鼠标方向微微倾斜，另有一块跟随鼠标的高光
- **拖尾粒子 + 点击涟漪**：Canvas 绘制，慢速移动时不喷，不骚扰
- **鼠标光晕**：一层柔光跟着走，照亮背后的夕阳
- **场景视差**：见上
- 触屏与 `prefers-reduced-motion` 下会自动关掉这些

### 三本课本封面

CSS 手工复刻配色版式（非原图）：选择性必修1《化学反应原理》、选择性必修2《物质结构与性质》、选择性必修3《有机化学基础》。

### 科学计算器 LCD

点骰子时浮出算式，三段依次抖出 —— `6×RAN+0.5` → `4.282` → `Rnd = 4`，和判定结果永远自洽、可验算。决斗时切成双通道 `RAN ≥ 0.9` 对决。

### 氛围层

夕阳天光 / 窗框投影 / 窗帘飘动 / 纸张纹理 / 胶片颗粒 / CRT 扫描线 / 暗角。移动时逐格点亮 + 镜头跟随；底部轮播怀旧字条。

## 背景音乐

**默认是关的，点了才响**（浏览器也要求先有一次用户交互）。

点开场或游戏顶部的音符按钮开启，放的是 **班得瑞演奏版《安妮之歌》（Annie's Song）**：

- 文件在 `audio/annie-song.flac`（44.1kHz / FLAC / 3 分 17 秒 / 16.1 MB），单曲无缝循环
- 开启后按钮会显示成 `♪ 安妮之歌`，1.8 秒淡入，避免一上来就怼耳朵
- 关掉只是暂停，再点继续从头淡入
- 如果哪天把 `audio/tracks.js` 的数组清空，会自动退回内置的**现场合成钢琴**（C → Am → F → G 循环，1 : 0.2 : 0.06 三次谐波 + 3 秒指数衰减 + 远处广播底噪，零文件零下载）

### 换别的歌

把音频丢进 `audio/` 目录，然后在 `audio/tracks.js` 里登记：

```js
window.EPF_AUDIO_TRACKS = [
  { title: '安妮之歌', subtitle: "Annie's Song · Bandari", src: 'audio/annie-song.flac', loop: true },
  { title: 'Your Smile', src: 'audio/your-smile.mp3' }
];
```

只有一首（或标了 `loop: true`）就单曲循环；多首则顺序播放、放完接下一首再绕回。数组为空就回到合成音。

支持的格式就是浏览器能直接播的那些：`.mp3` `.ogg` `.m4a` `.flac` `.wav`。

### 觉得不好听，告诉我往哪个方向调

| 你想的 | 我改哪里 |
|---|---|
| 音量更小 | `js/audio.js` 里的 `volume: 0.55` |
| 淡入慢一点 | `fadeInElement()` 里的 `1800`（毫秒） |
| 换成合成音 | 把 `audio/tracks.js` 的数组清空 |
| 合成音更慢 / 更密 | `schedulePhrase()` 的 `1500 + Math.random()*1500` |
| 换成别的和弦走向 | `PROGRESSION` 数组 |

## 已知取舍

| 决策 | 原因 |
|---|---|
| 104~118 的元素中文名（𬬻 𬭊 𬭳 …）在多数系统缺字，棋盘上退回显示元素符号 | 扩展 B 区汉字字体覆盖不全，硬显示会出豆腐块 |
| 特殊格用「斗 / 眠 / 再 / 风」而不是 emoji | `⚔` `🌪` 在 Windows 会退化成叉号或彩色 emoji，破坏整体调子 |
| 三套封面是 CSS 复刻，不是扫描图 | 版权 + 离线可用 |
| 棋盘格子按容器实测尺寸自适应，窄屏宁可横向滚动 | 手机上 18 列塞不下，压小字号会让中文名糊掉 |
| 联机不做断线重连 | 回合制游戏，重连价值低于复杂度；断了重进新房间即可 |
| 背景音乐默认关闭，默认曲目是本地《安妮之歌》 | 自动播放会被浏览器拦；音频只放本地登记表里点名的文件，不偷偷下歌 |
| 音频用 `<audio>` 直接播而不是塞进 Web Audio | 200 秒的曲子解码进内存太重，媒体元素能流式播、能循环、关掉就是暂停 |
| 知识卡用 `:has()` 给整卡上类别色 | 少写一层 JS 传参；不支持 `:has()` 的浏览器只是少个边框色，不影响阅读 |
| 磁吸倾斜只在鼠标设备上开 | 触屏没有 hover，倾斜会变成误触后的抖动 |
